## 2. 核心不变量

以下条件是测试设计的共同断言：

1. 首页在无进行中训练时，能直接完成“编排或查看计划 → 修改 → 保存 → 开始记录”。
2. 同一天重复保存或重试不会产生重复的一次性计划、日程或训练会话。
3. 修改未开始的今日计划只影响目标计划；不能改写已完成历史或进行中训练快照。
4. 保存失败必须保持原计划完整，不能出现旧计划已跳过但新计划未创建的部分写入。
5. 首页总容量只统计 `completed session + completed set + 非热身组 + kg`；负重量或负次数不产生负容量。
6. 日期按训练会话真实开始时间归日；同日多场训练合并，只显示最近 6 个实际有训练数据的日期，不用空自然日填充。
7. 完成或编辑训练记录后，首页容量、历史详情和进度页必须使用同一口径并在重启后保持一致。
8. 空数据、单点、零容量、超大容量和异常旧数据均不能导致崩溃、无穷值、错误百分比或不可读图表。
9. 覆盖安装不得通过卸载、清空容器或重新播种来制造“测试通过”。

## 3. 标注规范

### 优先级

- `P0`：数据丢失/改写、错误容量进入后续分析、重复会话、部分写入、升级破坏。任何一项失败立即阻断。
- `P1`：今日计划主闭环、持久化、日期口径、关键入口或恢复失败。要求 100% 通过。
- `P2`：视觉、可访问性、性能、极端布局和非主路径。要求至少 95% 通过。

### 执行层

- `[UNIT]`：纯计算单元测试，无需真机。
- `[SERVICE]`：内存或临时 SwiftData 集成测试，无需真机。
- `[SIM-UI]`：iOS 模拟器 UI 自动化，无需真机。
- `[GENERIC-BUILD]`：iPhoneOS 构建/签名校验，无需连接真机。
- `[DEVICE-AUTO]`：连接真机后的安装、启动、进程或数据库自动回读。
- `[DEVICE-MANUAL]`：真实 iPhone 上的人工触控、视觉和系统中断验收。

### 结果状态

- `✅ 通过`：断言全部满足，并有日志、xcresult、数据库摘要或录屏证据。
- `❌ 失败`：产品断言失败；记录最小复现步骤、实际值与期望值。
- `⚠️ 不稳定`：重复运行结果不一致；不计为通过。
- `⛔ 阻塞`：设备、权限或测试环境不可用；不是产品失败，但不得给 Go。
- `⬜ 未执行`：尚未运行；不得写成失败或 0 分，也不得写成通过。
- `➖ 不适用`：经审核确认与本候选无关，并记录原因。

## 6. 执行流程与停止条件

### Gate 0：冻结候选

记录版本/Build、Git HEAD、dirty scope、相关源文件哈希、Xcode/iOS 版本和测试数据集。后续每条结果必须指向同一候选；源代码变化后旧结果自动失效。

### Gate 1：无需真机的确定性测试

依次执行 UNIT → SERVICE → SIM-UI。优先补齐所有 P0/P1 `⬜ 未实现专项`；任何 P0/P1 失败立即停止进入真机阶段。

### Gate 2：稳定性与完整回归

首页专项连续 3 轮无重试通过，再执行完整 unit/UI 回归。单独复跑通过但并发失败时先区分模拟器、旧进程、fixture 和产品缺陷；未归因前标为 `⚠️ 不稳定`。

### Gate 3：无需连接真机的设备包检查

构建 arm64 iPhoneOS 包，验证签名、entitlements、bundle/version/build 和生产包无测试载荷。这一步仍不代表安装或真机通过。

### Gate 4：真机数据保护

连接并解锁 Edward_iPhone，确认 Developer Mode/DDI 可用；先备份活跃 App Group，再记录数据库完整性、数量和内容指纹。任何备份或基线失败都标为 `⛔ 阻塞`，不继续安装。

### Gate 5：覆盖安装、启动与回读

覆盖安装，不卸载；分别记录安装成功、版本回读、启动成功、进程回读和数据库 quick_check。若设备锁屏导致启动失败，安装状态仍可为通过，但启动与后续验收保持阻塞。

### Gate 6：真实业务闭环

用独立命名的验收计划完成“加入 → 查看 → 修改 → 重启 → 开始 → 记录 → 完成 → 历史编辑 → 容量回算”。每一步记录相关 UUID/数量变化，禁止只凭页面截图判定数据正确。

### Gate 7：人工体验与最终结论

检查首页首屏优先级、操作步数、可读性、键盘、安全区域、动态字体和 VoiceOver。最后再次备份并回读数据库，再给出 Go / Conditional / No-Go。

### 立即停止条件

- 旧训练、快照或组记录数量减少，或历史内容指纹变化。
- 计划保存产生部分写入、重复日程或重复训练会话。
- 首页、历史、进度三处容量不一致。
- 崩溃、数据库校验失败、升级后无法启动。
- P0/P1 出现 flaky，或必须真机的项目被跳过。
