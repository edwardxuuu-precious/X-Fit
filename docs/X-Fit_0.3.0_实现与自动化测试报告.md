- 结论：功能开发、自动化测试、模拟器视觉检查、真机覆盖安装和 Notes 真实历史记录同步均已完成；剩余为用户在真机内抽查记录及日常训练流程验收。

## 1. 本次实现

### 当天自适应训练

- 可按日期和肌群编排一次性训练菜单。
- 基于最近 28 天完成历史计算肌群恢复状态。
- 最近同肌群菜单中的动作会降权，减少连续重复完全相同菜单。
- 支持刷新推荐、自由选择动作、排序以及调整组数、次数、重量和休息时间。
- 当天已有固定计划时，可选择由自选菜单替代；旧计划标记跳过，不删除历史。

### 上次强度与注意事项

- 推荐卡显示该动作最近一次完成日期、训练名称、完成组、最佳组、平均 RIR 和训练容量。
- 根据上次完成次数和 RIR 给出维持、小幅加重或降低负荷建议。
- 动作库说明、上次动作备注和训练备注会进入本次提醒。
- 训练中可记录动作状态、疼痛和技术提醒，完成后在历史详情及下次推荐中回显。

### 历史训练同步

- 支持逐场手动补录过去训练。
- 支持 CSV 批量预检和确认导入。
- 同一个 `session_id` 重复导入会跳过。
- 缺失动作会作为自定义动作创建。
- 未完成行不会写入历史；非法字段会在写入前报错。
- 备份数据结构升级到 schema v3，并兼容旧备份缺失的新字段。

## 5. Notes 真实历史同步结果

- 来源：macOS Notes 的“健身”文件夹，共 5 份周记录。
- 日期范围：2026-07-01 至 2026-07-30。
- 可导入记录：14 场训练、97 个动作实例、430 个完成组。
- Notes 没有记录 RIR，导入时保持为空。
- Notes 没有具体开始时间和时长，使用当天 00:00 和 60 分钟占位，并在训练备注中说明。
- `One side` 重量按原始单侧数字保存，不猜测杠铃或器械起始重量。
- 斜杠递减组拆成连续完成组，原始写法保留在备注。
- 休息日、跳过日、仅有氧描述和含义不明确的残缺记录不伪造为完成组。

模拟器首轮导入同样得到 14 场、430 组和 43 个新建动作；再次导入得到 0 场新增、14 场跳过。独立内存数据库校验还确认了 CSV 包含 50 个唯一动作，其中真机和模拟器只有 43 个需要新建，因为 7 个名称已匹配内置动作库。
