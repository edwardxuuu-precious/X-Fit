- 版本：X-Fit 0.3.0（Build 8）
- 测试日期：2026-07-31
- 测试环境：Xcode 26.6、iOS 26.5 Simulator、iPhone 17
- 结论：功能开发、自动化测试、模拟器视觉检查、真机覆盖安装和 Notes 真实历史记录同步均已完成；剩余为用户在真机内抽查记录及日常训练流程验收。

## 1. 本次实现

### 当天自适应训练

- “训练”标签默认进入“今日编排”，无需从首页快捷入口绕行。
- 可先只保存当天菜单，或保存后立即开始训练；再次进入会载入并继续编辑今天的菜单。
- 可按日期和肌群编排一次性训练菜单。
- 基于最近 28 天完成历史计算肌群恢复状态。
- 最近同肌群菜单中的动作会降权，减少连续重复完全相同菜单。
- 支持刷新推荐、自由选择动作、排序以及调整组数、次数、重量和休息时间。
- 当天已有固定计划时，可选择由自选菜单替代；旧计划标记跳过，不删除历史。
- 训练进行中可按身体状态临时加动作、增加组、减少最后一个未完成组，或移除尚未开始的动作。
- 首页“今日训练”只呈现当天唯一菜单，移除无实际目标页的“查看全部”；训练进行中的入口明确区分“临时加动作”和“调整训练量”。
- RIR 表头可点开中文说明，选项同时显示“还能做几次”，不确定时可以不记录。
- 每个动作明确显示计划默认组间休息；完成一组后的休息卡同时显示默认值与实时倒计时，并提供“−30 秒 / +30 秒”和结束休息控制。
- 调整休息时间后会立即保存新的结束时间并重排休息结束通知；减到 0 秒时直接结束并取消通知。
- 首页训练卡会结合训练名称和当天动作肌群，在推、拉、腿、核心与综合五类背景中自动选择；混合目标同分或无法识别时使用综合图，不随机猜测。
- 四张新增高清图作为离线资源打包，运行时不依赖网络；原图、摄影师和 Unsplash License 记录见《X-Fit 训练背景图来源》。

### 首页导航去重

- 移除首页“快捷入口”四宫格；“训练”和“进度”由底部标签作为唯一一级入口。
- 日程收口到首页“接下来 → 管理日程”；无后续安排时仍显示空状态和管理入口。
- 历史同步从首页迁移到“我的 → 更多”，更符合低频数据管理的层级。
- 营养仅保留“我的 → 健康概览”的当日状态卡，移除同页重复的文字列表入口。

### 上次强度与注意事项

- 推荐卡显示该动作最近一次完成日期、训练名称、完成组、工作均重、最佳组、平均 RIR 和训练容量。
- “训练”页可选择“减脂·容量优先”或“均衡·渐进超负荷”；当前默认减脂容量模式。
- Notes 导入缺少 RIR 时不再视为余力充足，也不会只因达到次数上限就建议加重。
- 减脂模式优先保留上次有效组数，以逐次×重量加权得到的工作均重维持容量；只有容量未下降、RIR 完整且每组至少 3 RIR 时才显示可选微加重，并明确组数不减。
- 次数未达目标、出现 0 RIR 或容量较上次下降超过约 10% 时，建议减重约 5–10% 并优先完成原定组数。
- 动作库说明、上次动作备注和训练备注会进入本次提醒。
- 训练中可记录动作状态、疼痛和技术提醒，完成后在历史详情及下次推荐中回显。

### 历史训练同步

- 支持逐场手动补录过去训练。
- 支持 CSV 批量预检和确认导入。
- 同一个 `session_id` 重复导入会跳过。
- 缺失动作会作为自定义动作创建。
- 未完成行不会写入历史；非法字段会在写入前报错。
- 备份数据结构升级到 schema v3，并兼容旧备份缺失的新字段。
- Notes 导入记录启动时会自动移除名称末尾的 `(Notes)`；仅清理带导入标识的记录，不改写用户手动名称。
- 历史卡片使用稳定的显式详情目标；详情会显示日期、时长、容量、动作、逐组重量/次数/RIR 和备注，返回后保持在历史列表。
- 历史详情右上角可编辑训练名称、日期、时长、整场备注、每个动作备注和逐组重量/次数/RIR。
- 编辑器支持增减完成组、补充遗漏动作或移除误录动作；保存后重新计算容量，并更新后续恢复和动作建议。

### 周/月进度可视化

- 首页进度卡支持“周 / 月”即时切换；周视图使用周一至周日，月视图按自然周聚合。
- 进度环只使用周期内未跳过的计划作为目标；没有计划时明确显示“暂无计划”，不会把已有历史自动伪造成 100% 计划完成率。
- 训练次数、工作组、训练容量和时长只来自周期内已完成的训练；容量只统计已完成且非热身的工作组。
- 容量柱图使用单一品牌色和直接日期刻度；零数据时显示空状态，不用虚构最小柱高。
- 同期对比使用“上周同期 / 上月同期”的相同已过时段，避免用尚未结束的本周或本月对比完整上一周期。

## 7. 减脂训练建议的证据边界

- 负荷较低与较高的阻力训练，在努力程度足够时可得到相近的肌肥大结果；更高负荷对最大力量更有优势。因此减脂容量模式不要求每次都追逐最重组，而是优先稳定有效组、次数和动作质量。
- 热量限制期较高训练量可能有助于保留瘦体重，但现有研究不足以证明训练量越高越好。X-Fit 因此保留高组数倾向，同时把近期组数、RIR、容量下降和恢复状态作为护栏。
