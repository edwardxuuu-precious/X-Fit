# X-Fit 0.2.0 人工测试流程说明

本文与《X-Fit 0.2.0 真机人工测试清单》配套使用。目标是验证真实 iPhone 上的权限、后台、锁屏、系统健康数据和升级数据安全；这些行为无法由模拟器自动化完全替代。

## 1. 测试前准备

1. 保持 iPhone 解锁并连接 Mac，确认主屏幕已出现 `X-Fit`。
2. 不要删除旧 App。当前安装是覆盖升级，旧数据是否保留必须先验证。
3. 打开 iPhone 的 `设置 → 隐私与安全性 → 开发者模式`，保持已启用。
4. 确认系统“健康”App可以正常打开；如需测试身体数据读取，先在健康中准备一条体重或体脂数据。
5. 准备“文件”App中的一个可保存目录，例如 `我的 iPhone → X-Fit Test`。
6. 先打开《X-Fit 0.2.0 真机人工测试清单》，边测边填写结果。

建议先截取升级前后计划数量、历史数量和进行中训练状态。测试中发现数据异常时，先停止继续操作并保留现场。

## 2. 状态判定标准

- `通过`：操作结果和清单预期完全一致，退出或重启后仍保持。
- `失败`：崩溃、数据丢失、重复记录、状态错误、权限行为错误，或稳定可复现的界面阻挡。
- `跳过`：当前没有必要的系统数据或测试条件，例如健康 App 没有体脂数据。必须写明原因，不能当作通过。

完成边界也要分开记录：

- 本地实现完成：代码存在且能编译。
- 自动化测试通过：模拟器测试验证了明确断言。
- 已安装到真机：安装命令成功，不代表用户流程成功。
- 真机人工通过：你按本文操作并确认真实结果。

## 3. 推荐执行顺序

### 流程一：品牌、升级与数据保留

1. 解锁 iPhone，确认主屏幕名称为 `X-Fit`、图标为黑底荧光绿图形。
2. 打开 X-Fit，确认能进入首页。
3. 依次查看 `训练`、`进度`、`我的 → 训练历史`。
4. 将升级前已有的计划和历史与当前数量对比。
5. 从多任务界面划掉 App 后重新打开；最后重启 iPhone 再确认一次。

通过标准：无闪退，旧数据不减少、不重复，App 不要求通过“删除并重装”才能使用。

### 流程二：建立一套可追踪测试数据

1. 打开 `训练 → 动作库`，点右上角 `+`。
2. 创建动作：名称 `人工测试划船`、肌群 `背部`、器械 `弹力带`、休息 `60 秒`，备注 `X-Fit 验收`。
3. 再创建一次同名动作，确认被拒绝。
4. 返回 `训练计划`，点右上角 `+`，创建 `X-Fit 人工验收`。
5. 选择今天对应星期，加入 `人工测试划船` 和至少两个内置动作。
6. 为动作设置容易完成的目标，例如每项 1 组、8–10 次、低重量、60 秒休息。

通过标准：自定义动作可搜索、可加入计划；同名保护有效；保存后首页和日程能看到计划。

### 流程三：日程改期、跳过与临时加练

1. 首页点 `日程`。
2. 找到待训练卡片，点 `… → 调整日期`，改到明天。
3. 关闭并重开 App，确认原日期没有重新生成。
4. 点改期后的卡片 `… → 跳过训练`，填写 `恢复日`。
5. 确认卡片显示已跳过和原因，再执行 `恢复训练`。
6. 点右上角 `+`，用 `X-Fit 人工验收` 在后天添加临时训练。
7. 重复添加相同计划和日期，确认出现防重复提示。
8. 删除临时安排，确认训练模板仍存在。

通过标准：具体日期状态是权威记录，模板刷新不能覆盖人工改期或跳过决定。

### 流程四：训练、锁屏、强退恢复和完成

1. 确保今天有一场待训练；需要时把测试计划改到今天。
2. 首页点 `开始训练`。
3. 第一组输入一个小数重量，例如 `12.5 kg`，输入次数和 RIR，但先不要完成。
4. 返回首页再进入进行中训练，确认输入仍在且没有第二个训练会话。
5. 点完成第一组，确认休息倒计时开始。
6. 记录当前时间，锁屏 30 秒后解锁；剩余时间误差应不超过 2 秒。
7. 再次开始休息并切到后台，等待结束；确认只收到一次提醒。
8. 回到 App，填写训练备注 `锁屏与恢复测试通过`。
9. 从多任务界面强制关闭 X-Fit，再重新打开。
10. 选择继续训练，核对逐组输入、完成状态和备注。
11. 完成训练并确认；进入历史详情核对时长、容量和逐组数据。

通过标准：后台计时基于绝对时间；强退后最多只允许丢失尚未结束输入的当前编辑值，已保存组和备注不能丢失；完成后只产生一条历史。

### 流程五：放弃训练边界

1. 再开始一场测试训练，至少输入一组数据。
2. 点页面底部 `放弃本次训练`。
3. 先点 `继续训练`，确认不会误放弃。
4. 再次操作并点 `放弃并退出`。
5. 返回首页、日程、历史和进度检查状态。

通过标准：放弃会话不计入已完成统计；关联日程恢复为等待开始；不会删除以前的完成历史。

### 流程六：营养和身体数据

1. 首页点 `营养`，设置你的每日目标。
2. 今天新增一餐 `测试早餐`；记录热量和三大营养素。
3. 编辑餐食并观察汇总变化，再长按删除。
4. 切到前一天新增不同餐食，再切回今天。
5. 打开 `我的 → 身体数据`，新增今天体重。
6. 再新增一个较早日期的不同体重，检查趋势；测试编辑和删除。

通过标准：汇总随增删改立即一致；不同日期互不串数据；身体趋势按日期排序。

### 流程七：通知权限与提醒同步

1. 打开 `我的 → 右上角齿轮`。
2. 开启 `训练日提醒`，系统弹窗选择允许。
3. 设置一个接近当前时间的提醒时刻，并确保未来有一场训练。
4. 把该训练改期，观察旧时间不再提醒、新日期能够提醒。
5. 测试完成后可在系统设置关闭 X-Fit 通知，回 App 确认显示拒绝状态且训练功能不受影响。

通过标准：权限拒绝不能阻塞核心功能；改期、跳过或删除训练必须同步撤销旧提醒。

### 流程八：Apple 健康

1. 在设置页点 `连接 Apple 健康`，只授予你愿意提供的权限。
2. 完成一场至少持续 1 分钟的训练。
3. 打开系统“健康”App，查找训练记录。
4. 确认类型是传统力量训练，开始和结束时间正确，没有伪造的心率或热量。
5. 如果健康里已有体重或体脂，返回 X-Fit 点 `导入最新身体数据`。
6. 在身体数据页确认最新记录及数据来源。

通过标准：本地训练完成不依赖 HealthKit 成功；拒绝或写入失败不能撤销 X-Fit 中已完成的训练。

### 流程九：JSON 备份、CSV 和恢复

1. 在 `设置与数据` 点 `生成完整 JSON 备份`。
2. 点 `分享最新备份`，保存到“文件”App。
3. 点 `生成训练 CSV` 并保存；用“文件”预览，确认列名和测试训练数据存在。
4. 返回 X-Fit 点 `导入 JSON 备份`，选择刚保存的文件。
5. 阅读预检数量，再点 `导入缺失记录`。
6. 再次导入同一文件。
7. 检查计划、历史、营养和身体数据数量没有翻倍。

通过标准：导入前必须预检；相同 UUID 跳过，不静默覆盖；现有营养目标保持单例。

## 4. UI 与可访问性抽查

1. 把系统文字调到一个较大档位，检查首页、训练页和进行中训练页。
2. 开启 VoiceOver，确认底部四个标签和“打开设置”等主要按钮可读。
3. 检查中文键盘、小数键盘和键盘收起行为。
4. 开启“减少动态效果”和低电量模式，执行一次开始/退出/恢复。

以下情况视为失败：关键按钮被底部标签栏遮挡、无法滚动到操作入口、文字重叠导致无法理解、键盘遮住保存按钮且无法收起。

出现崩溃、数据丢失、重复训练会话或备份导入破坏时，请先停止后续测试；这四类属于阻断问题。
