## 2. 三条必须闭环的用户流程

### F1：当天菜单内原地补录

`今日训练/日程指定日期 → 调整菜单 → 添加动作 → 搜索无结果 → 新建并加入 → 保存当天菜单 → 开始训练 → 历史快照/备份保留参考链接`

通过标准：不离开编排上下文；原菜单不丢失；新动作只生成一条；保存后加入正确日期；训练快照不受后续动作编辑影响。

### F2：外部资料分享后加入当天菜单

`Safari/其他 App → 分享到 X-Fit → Extension 写入待确认草稿 → 返回 X-Fit → 补全并保存到动作库 → 进入当天菜单搜索并加入 → 开始训练`

当前产品边界：分享草稿保存后进入动作库，**不会自动加入当天菜单**；用户仍需在当天菜单选择一次。测试不得把“保存到动作库”误报为“已加入今天”。

### F3：训练进行中临时加动作

`训练进行中 → 临时加动作 → 搜索/原地新建 → 自动加入当前会话 → 生成默认训练组 → 完成训练 → 历史显示独立快照`

通过标准：不产生第二个会话；不允许重复加入；已结束会话不可再修改；动作资料与参考链接进入本次会话快照。

## 6. 执行顺序与停止条件

1. 固定 build、Git 工作区状态和测试数据 fixture；记录本轮 `run_id`。
2. 执行 `CODE → UNIT → SIM-UI`；P0 失败立即停止进入真机阶段。
3. 连续三轮专项回归，禁止用重试掩盖 flaky；波动项标记 `FLAKY` 并按失败处理。
4. 执行 `SIGNED-BUILD`，回读主 App/Extension entitlements、profile 有效期和嵌入关系。
5. 连接并解锁真机，先备份与记录数据库指纹；备份或 `quick_check` 失败立即停止覆盖安装。
6. 覆盖安装，不卸载、不清空；完成启动和升级数据守恒检查。
7. 依次执行 F1、F2、F3，再做锁屏、后台、强杀、重启和辅助功能测试。
8. 回读最终数据计数、快照内容、备份恢复结果；再计算真机分与总分。

立即停止并保留现场的情况：数据计数异常下降、数据库完整性失败、历史快照被改写、重复 session、Extension 反复崩溃、覆盖安装要求删除 App、待确认草稿出现半写或误删。

|---|---|---:|
| `PASS` | 已执行且有证据，全部断言满足 | 1 |
| `FAIL-PRODUCT` | 可复现的产品行为不符合断言 | 0 |
| `FLAKY` | 同 build/fixture 结果不稳定 | 0，按失败处理 |
| `BLOCKED-ENV` | 锁屏、DDI、签名、Runner、设备断连等导致未进入有效测试 | 0，不得写产品失败或通过 |
| `NOT-RUN` | 尚未执行 | 0 |
| `N/A` | 本 build 明确不适用，必须写原因和批准人 | 从该维度分母移除 |

单条记录必须包含：`ID、build、环境标签、设备/系统版本、前置数据、步骤、期望、实际、状态、缺陷归因、证据路径、执行人、时间`。失败至少附截图/录屏、稳定复现步骤和数据影响范围；自动化至少附 `.xcresult` 或等价日志。

### 8.1 权重

| **合计** | **100** | 70 分无真机 + 30 分真机 |

每个维度内测试项等权：`维度得分 = 维度分值 × PASS 数 ÷（总项数 − 合理 N/A 数）`。`BLOCKED-ENV` 与 `NOT-RUN` 不算通过。

### 8.2 优先级和硬门

- `P0`：数据安全、事务原子性、主链路和跨进程草稿。必须 100% PASS。
- `P1`：交互边界、状态机、回归和发布可靠性。必须 100% PASS；flaky 不允许放行。
- `P2`：效率、压力和体验优化。PASS 率至少 95%，未达标进入明确改进清单。

无论总分多高，以下任一项不满足都阻断发布：

- 任一 P0/P1 为 `FAIL-PRODUCT`、`FLAKY`、`BLOCKED-ENV` 或 `NOT-RUN`。
- 真机覆盖安装前后关键历史计数下降，或 `quick_check != ok`。
- F1/F2/F3 任一未完成真机闭环。
- Share Extension 无法从真实 Safari 出现、写入或被主 App 读取。
- 参考链接未进入历史快照或备份恢复后丢失。
- 专项三轮或完整回归不是 0 失败。

### 8.3 等级

- `95–100 + 所有硬门通过`：发布候选通过。
- `90–94`：条件通过，仅限内部验证；修复后重跑受影响项和完整回归。
- `80–89`：高风险，阻断发布。
- `<80`：不可接受。
- 真机层存在未执行或环境阻塞：只报告 `自动化阶段分 x/70`，最终分写 `未生成`。
