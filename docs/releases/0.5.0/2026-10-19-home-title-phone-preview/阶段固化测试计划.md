## 执行入口与停止条件

```bash
XFIT_XCODE_PROJECT=/tmp/xfit-home-title-phone-project-20261019/FitnessApp.xcodeproj \
XFIT_DEVICE_ID=00008150-001E49912122401C \
XFIT_ALLOW_DEVICE_INSTALL=1 XFIT_ALLOW_DEVICE_TESTS=0 \
XFIT_RUN_ID=20261019-home-title-phone-preview \
XFIT_BUILD_JOBS=3 \
XFIT_DERIVED_PATH=/tmp/xfit-home-title-phone-derived-20261019 \
scripts/xfit-stage-validation.sh device
```

- 统一入口先备份手机当前活动 App Group，SQLite 完整性通过后才构建和覆盖安装；永不卸载或清容器。
- 原手机数据为真源，不用模拟器数据回写手机，不直接写 SQLite。仅本地读取备份核对所有模型的原业务字段及外部资源。
- 设备离线/锁屏、签名失败或备份不完整时停止依赖动作。安装回执不确定时先读取设备状态、App 和进程，不盲目重装。
- 普通启动无测试参数；完整自动化与本人体验的未完成状态独立保留，不标阶段 GO。
