# 训练输入性能复测

本轮尚未测得真机端到端回显 P95，也没有把模拟器或保存次数的改善等同于手机手感。对应 `REQ-20260927-100827 / AC-03、AC-04`。

## 本阶段采用的已确认口径

最新本人决定为[原训练需求C-05及当前性能出口](../requirements/2026-09-27/100827_training-experience.md#1014-当前性能出口取消严格物理p95要求)、收尾需求C-12：严格物理触键→可见画面P95测试要求已取消，不是继续延期；不再列待办、不要求第二台设备。旧NOT_RUN/null及原100ms目标仅保留历史，不能标PASS。已有App侧采集、数字/中文输入保存正确性、已接受手感及明显卡顿/丢字处理保留，不新增App代理100ms硬门、不重测已过项。

下列测量说明保留为既有方法和诊断解释，不构成取消项目的自动重开授权；只有新的实际卡顿/丢字或本人明确要求才针对受影响路径有限诊断。严格物理P95不在该默认诊断任务内。

## 对照条件

1. 安装前先记录手机型号、iOS、实际安装版本与构建标识，保留原活动数据备份；不把当前 Git HEAD 当作手机旧版源码。
2. 使用同一手机、同一输入法、相近温度/电量、同一组接近真实规模的历史数据。在试验副本或专门测试训练中测试，不修改过去完成组。
3. 固定输入序列至少重复 20 次：重量 `25.125`、清空重输、次数/RIR、粘贴中文备注、拼音候选确认、动作中英文搜索、快速切换、最后一位尚未等待300ms时离开/后台。
4. 用户确认覆盖安装权限后才执行统一 device 层。保留安装前后及测试后 UUID/数量/关键字段守恒证据；禁止卸载或清库。

## 两种测量不能混用

- App 内 profiling：`--workout-input-profiling` 为显式诊断开关，使用 signpost 观察“App 收到编辑事件 → 下一CADisplayLink回调”的代理区间、持久化耗时和超过250ms的帧间隔；通过 Instruments 的 Points of Interest / Animation Hitches 收集。仅记录时间、数量，不采集输入文字、重量或备注内容。该回调不证明文字像素已显示，帧间隔不单独证明App主线程根因；以实际代码和trace为准。
- 实际事件：subsystem `com.xfit.input`、category `PointsOfInterest`；`InputNextFrame`（编辑回调到下一 CADisplayLink 回调）、`WorkoutSave`（训练页保存区间）、`FrameGapOver250ms`（帧回调间隔超过250ms）。停止采集时输出样本数、P95/最大代理耗时、长间隔及保存次数；最多保留10,000个耗时样本，进入后台/离开界面停表，不将后台时间计作卡顿。多个界面以 owner 管理共享采集器；一次保存间隔不代表所有系统自动保存。
- 真正回显体验：手机录屏/高帧率外部录像核对触键、中文候选确认与文本实际可见帧。App 代理区间不包含键盘跨进程延迟，不等于触键到像素时间；帧间隔也不能单独证明停顿根因在App。

既有采集报告分别列出样本数、可取得的App代理P95/最大值、>250ms异常、保存耗时/次数、数据规模和实际版本；没有可信旧版基线不声称改善幅度。原样本/保存回读范围保留，不把不足样本或无样本日志0视为测量值。严格端到端P95要求现已取消，历史未测不由代理数值代填；本批App侧采集及保存回读已取得的范围见原无线摘要，不再无变化重跑。

## 正确性与停止条件

- 核对失焦、勾组、完成训练、退后台后的最后字符/小数/RIR是否保存；中文组合文本不应被格式化或外部状态更新打断。
- 明确注入保存失败，必须有提示且不能播放完成庆祝；恢复后回读，不以画面显示等同落库。
- 有记录丢失、候选词被截断、核心数据减少或保存失败静默时停止覆盖安装后续推广，保留诊断和用户原数据。
- 沿用本人已接受的数字/中文手感，不重复索要同一确认；未报告边界或新卡顿分别按实际记录，自动化不代填本人验收。
