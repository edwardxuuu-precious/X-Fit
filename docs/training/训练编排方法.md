## 1. 先确定目标与证据覆盖

每课明确一个主目标，区分常规力量/增肌、爆发技术、协调稳定和有氧。选择动作、剂量和结束组的标准随目标变化。

实际以App完成记录为准；已由本人确认实际完成的Notes可作为待同步来源。区分来源日期、读取日期、训练开始时间是否已知；午夜的内部日期占位不是实际开始时间。按请求日期选不晚于该日、有效日期最新的TrainingPreferenceRevision，并检查周编排及临时规则期限。

将本人反馈、直接观察、未知和编排建议分开。没有RIR或未区分热身/工作组时，只统计原始记录行与已知分类；App的非热身标志本身不证明旧Notes每一行都是有效组。

### 1.1 先核目标排序、约束和时效

先读取本人最新目标、期限、训练时间和当前健康/器械限制；与App目标、近期实际冲突时并列并只问会改变本次决定的差异，不静默覆盖。用FITT-VP逐项核对频率、努力/负荷、时长、动作类型、容量和进阶，但不把框架变成必须加满的清单。已有充分事实时不重问整份档案。

| 目标 | 本轮能观察的过程 | 不能据此宣称的结果 |
|---|---|---|
| 减脂中保留肌肉和力量 | 同口径主项的次数/负重/努力、恢复、可得的近期晨重趋势 | 单次体重下降或力量维持不证明身体组成变化 |
| 力量/增肌 | 目标动作的可比表现；工作组、质量、努力及后续恢复 | 总吨位或酸痛不证明力量/肌肉已增长 |
| 爆发、协调与反应 | 已掌握动作的速度/技术，或用户指定场景的可重复任务表现 | 抗阻公斤数、高次数高翻或一般快步不能代替功率/反应测量 |
| 有氧 | 实际主段时长、谈话感受/用力、疲劳和下一次力量表现 | 没有测试不声称已精确落在个人生理Zone 2或已改善心肺 |

近期体重、能量/蛋白摄入和恢复缺失时不假定正在适度热量缺口。沿用用户现有医生/营养师边界，不由训练研究设置高蛋白、肉量或激进能量缺口；仅询问影响训练接受程度的必要信息。减脂期同口径表现维持可以是合理过程目标，不要求每课加重或用额外有氧追赶旧期限。

## 2. 两个历史窗口与后续活动

| 范围 | 要回答的问题 | 输出 |
|---|---|---|
| 最近7天及本周已确定实际 | 哪些动作模式重复、哪些已承受较多暴露？ | 膝主导、髋主导、腿弯举、单腿、足踝/跳跃及其他部位的实际摘要；分别列已知工作组和性质不明行 |
| 近4–6周 | 同动作的表现是否可比，曾使用怎样的次数与余力？ | 相同动作UUID、器械、单位、侧别及可核设置的参考；不可比原因保持显式 |
| 后续约48小时的已确定活动 | 当天加量是否挤占后续主项、跳绳或恢复？ | 本次保留、减少、替代或省去的动作位及取舍 |

这些窗口是本项目查阅数据的实用范围，不是经过个人验证的恢复公式。旧课表不自动续排；缺记录不代表没有训练。既有App建议负荷仍受近42天、同动作/器械、kg、完成非热身组及RIR至少2等条件约束，不与历史录入预填规则混用。

## 3. 对齐动作与计量后再比较

- 历史补录保留动作原名；含糊名称或不同器械不合并为近似动作。单位、重量侧、次数侧各自核实；器械刻度不当kg，不从总重推单只。
- 复合动作对多个肌群的贡献有重叠，不能给每个参与肌群各计一个完整独立组；跳绳次数、技术组、等长时间和抗阻工作组分别报告。
- 新方案注明单侧口径，例如左右各做3轮按计划记3组；已有实际保留原记录口径，不倒推未知侧别。
- 同一动作可比时再比较负重、次数、RIR及动作质量。跨器械的数字、缺失余力或不同动作幅度不能证明进步、退步或达到加重条件。

### 3.1 力量表现档案

具体重量编排先读[力量表现档案](力量表现档案.md)，再核对其所指实际记录；档案用于定位与解释，不能替代新发生的训练。按动作UUID/实际变式、器械及设置、重量单位和口径分开保存最近表现，不把“腿部力量”压缩成一个公斤数。

每条证据包括训练日期、实际重量×次数×组、实际RIR或未知、重量侧/次数侧、热身性质、动作质量/不适、来源定位和可比性。杠铃明确是否含杆；哑铃明确每手/两手合计；器械明确显示值、总加片/每侧加片以及空载是否包含。原字段或原文冲突时并列保留，澄清只作为新注记并绑定具体动作/来源日期/字段，不回填或改写旧完成组。确认每侧片重不等于确认杆重、次数侧别或其他动作的记法；总重仅在附加项明确时计算，否则给公式或明确条件的例子。

肌群层记录膝主导、髋主导、屈膝、单腿和足踝等已有能力证据、近期暴露与缺项。它帮助选择动作、保留/削减容量、发现需要采集的动作，不用来从深蹲/臀推换算腿举或高翻重量，也不按跨机器吨位评定肌群强弱。

### 3.2 为每个动作选择负重依据

| 证据情况 | 可给出的重量方案 | 结论边界 |
|---|---|---|
| 同动作、器械/设置和记重口径一致，有近期实际次数/余力/质量 | 具体首组重量与回退组范围；说明与历史及本次目标的关系 | 仍需热身核验；历史最大重量不自动成为起点 |
| 同动作但缺真实RIR、设置待核或只有较早记录 | 有条件的起点/范围、递增顺序和停止条件；标中/低置信度 | 可作人工教练候选；不宣称满足App自动建议门槛 |
| 只有相似动作或同肌群记录 | 用于选择较保守的试重路径；具体重量由本动作校准 | 不设置跨动作公斤数换算比例，不估精确1RM |
| 没有可比记录或口径仍冲突 | 明确所需最小澄清；同时给自重/轻杆/机器低档的短试重步骤 | 缺项只阻塞受影响的重量；其余动作照常完成规划 |

缺RIR不意味着整份计划只能留空：保留该历史为已完成表现证据，降低建议置信度并增加首组校准。实际RIR、处方目标RIR和备注文字分开；“保留3次余力”的旧计划说明不补成实际RIR=3。App编排导入的自动建议仍遵循原42天等筛选，人工提案及录入预填不混作自动建议。

### 3.3 负重方案的交付格式

每个负重动作至少有：**历史锚点/日期 → 可比性与置信度 → 热身重量递增 → 首组重量/范围 → 后续组重量/范围 → 当天调重与停止条件**。自重动作写自重。注明重量是建议、条件成立后的候选，还是训练后已校准值；可用器械最小档不明时写“邻近可用档”并保留原始候选数，不把小数档位当器械已具备。持重与支撑方式必须能同时完成；扶架单手哑铃与双哑铃视为不同负重分布，不能只改数字就认为可比。

常规抗阻先从可比实际中选择接近目标次数、且能留目标余力的非最大锚点；已校准且本人接受的实际成为下一课重复验证基线，再结合动作顺序、疲劳和已确认组型逐组安排。缺RIR降低置信度并增加首组校准，不自动让整课退回最早的低试重值。回退组在明确采用该组型且次数更多时适当减重；新建默认组型读取最新偏好，不由本周R6反推长期默认。晨练供能例外仅在本人当日实际符合时采用，不因早晨训练自动触发。

当天首组的调整采用轻量反馈：达到次数上限仍明显比目标多至少约2次余力时，下一组可加最小一档；在目标范围内则维持；低于次数下限或仅剩0–1次余力时降一档，必要时再降或结束动作。RIR是带误差的主观信息，和次数、动作速度/幅度及不适一起判断，不据估计的1次差异机械加重。短试重保持低疲劳，热身另计，不追加力竭测试或工作组。此校准用于达到本次目标，跨课增加工作重量仍按已确认的双进阶规则。

爆发动作优先参考同变式、同口径、能稳定接杠的记录，而非硬拉/深蹲。给出低疲劳递增和工作重量候选；历史高次数/RIR不能证明当前功率或技术，超过近期窗口的记录仅作背景。无当次速度仪器时使用已掌握的速度/接杠质量观察，不捏造速度、功率或1RM。降速、硬拽、追杠或接杠失稳即下调或停止，不为完成数值配额加组。

## 4. 根据问题选择调整变量

| 已有证据 | 优先动作 | 改判条件 |
|---|---|---|
| 目标次数完成但实际余力明显高于目标 | 先在目标次数内调整努力程度或最小档负重 | 动作稳定、真实RIR达到目标后再看是否仍需容量变更 |
| 低于次数下限，已接近力竭或动作失控 | 维持/下调负重，必要时减少或停止该动作 | 调整后规范完成且恢复允许 |
| 次数与RIR达到目标，但后段或次晨恢复明显变差 | 先减少后段组数、重复动作或后续冲击负荷 | 新反馈显示表现与恢复恢复正常 |
| RIR或工作/热身划分缺失 | 明确努力目标，后续采集少量关键字段 | 不要求回忆并补猜旧RIR，也不据行数机械加组 |
| 达到目标且恢复正常，仍持续认为刺激不足 | 提出一次有限容量调整供本人确认 | 不同时自动加重、加组、加频率，按下一次真实表现复评 |

常规抗阻沿用本人已确认的双进阶：同口径连续两次全部组达到次数上限、动作稳定且恢复正常，再考虑最小一档加重。数值与阈值以生效偏好为准。

爆发/举重动作单独处理：核实地面/悬垂、杠铃/哑铃/壶铃、接杠高度、本人熟练程度和可用场地。将需要协调与速度的动作放在疲劳较低的时段；用低疲劳组和充分休息维持速度及接杠质量。出现明显变慢、硬拉式硬拽、接杠不稳或疼痛时停止该动作。RIR不作为此类动作的主要进阶/结束标准，也不按硬拉或深蹲历史重量换算高翻重量。具体组次属于当次提案，不固化为所有人的通用处方。

### 4.1 动作数量、组数偏好与整课预算

先执行《用户训练偏好》中最新的整课输入`SESSION-PREF-20261026-01`：正常力量课6—8正式动作、90分钟上限、轻重搭配。主肌群至少4动作是另一项下限，不能把它当作整课目标。个人数值只在偏好文件维护；历史计划及其原方法版本不重写。

正常候选在展示及生成手机导入包前使用`scripts/xfit-validate-coach-plan.py <候选review.json>`核对整课/主肌群动作数、重点/常规组数、重中轻任务和完整估时。热身不凑数；技术/核心/足踝与常规抗阻分列，左右一轮按本次规定记录。估时采用计划休息上限、明确的每组执行假设、专项/一般热身、换器械和缓冲；无估时不算通过，实际体验仍待回收。结构PASS不等于个人容量最优、本人接受或设备已写入。

已完成场次只读复盘并保留原计划/实际；因本人不满意而修订时，先检查场次是否开始。新偏好和候选可独立维护，手机未读取时注明覆盖，缺失真实记录不补猜，也不直接修订已完成日期。

先读本人最新明确的组数偏好，并区分它与群体研究、实际完成反馈及App已生效偏好。当前本地输入`SET-PREF-20261016-01`要求常规抗阻至少3个工作组、重点复合主项至少4组；适用正常编排，不硬套到技术质量不达标、疼痛/恢复异常或明确减量时。组数偏好和新完整计划的确认分开，不能仅凭这次反馈写入手机。

同时读取《用户训练偏好》的`EXERCISE-PREF-20261020-01`，按当课主肌群核对不同抗阻动作数，再给重点和辅助动作分配工作组及充分休息。在目标时长内保留主肌群动作数下限、主项、必要方向和单腿任务；需要删减时先审视关联小肌群及低优先动作位，完整展示取舍，不能以去重复为由静默降破已确认下限。技术组、常规抗阻与核心分别统计，热身另计；异常停止/减量明确记例外。没有可靠余力/热身标记的旧Notes仍按原始记录行，不因新增偏好而重算有效组。

本人报告刺激不足时，同时查起始重量是否过轻、是否达到目标次数/努力程度、动作是否匹配及容量接受程度。若偏好未被满足且近期恢复允许，提出有限的组数调整；默认先维持已给重量候选，观察新增后段组能否保持次数/余力/技术。不要把“总组数更多”当作已证明本次增肌效果更好，也不同时自动加重、加组和加频率。

同一主项新增后段工作组时，允许邻近档减重以维持目标次数/余力；不能靠疲劳下的低质量重复完成最低组数。正常计划按本人偏好给足组数，实际若出现明确停止条件，可提前结束并记原因，不将一次异常当作永久改变偏好。

### 4.2 从周级剂量分配到动作菜单

1. 分开盘点当周已完成、待训练、热身/工作性质不明行、技术组及有氧主段；标明资料日期。原始行数与拟定工作组不可相加后包装为有效组总量。复合动作列主要目标与间接参与，直接/间接分开；未知分类不强制换算。
2. 若需比较重叠，可在同一已知工作组口径下列直接组数，并把间接组按0、0.5、1列成敏感性范围。0.5是研究模型的计数假设，不是某块肌肉真实承受一半剂量；不写入实际字段，不将上下界当个人最低量/最大恢复量。分类未知时先描述暴露，不计算假精确总数。
3. 按目标、可比表现、当前恢复、训练接受程度与时间，决定保留/减少/新增哪一个动作位。先保留目标主项、已验证动作与必要方向，再审视重复或无法校准的新动作；常规动作≥3组、重点复合≥4组仍按本人的有效偏好执行。移除动作或减组的理由是本次预算取舍，不能仅凭38行记录判断过度训练。

### 4.3 研究怎样进入个人处方

每次只更新会改变本轮动作的知识缺口，记录来源/日期、版本/人群、实际阅读范围、访问限制及与其他来源的重叠。外部研究支持原则，具体公斤数仍来自本人同口径实际或现场校准。新的群体结果不自动废弃已确认偏好、42天自动建议合同或历史版本。

| 高翻完成数字但速度、起拉或接杠质量变差 | 单独下调技术负荷、减少/停止技术组；下一次先验证快稳，再讨论负重 | 不能因为四组都完成而认定应加重，不从硬拉/腿举或主观RIR换算功率 |
| 新发疼痛、明显代偿或恢复影响日常活动 | 停止加量，针对诱发动作减量/省去并核实具体情况；需要时建议专业评估 | 不用“训练后正常反应”的猜测消解异常，也不推断诊断 |
| RIR/计量/关键恢复未知，或主观反馈与App矛盾 | 完成有证据部分，给有条件维持/校准候选，只追问受影响的最少字段 | 不把未知补零/正常；新机或新变式不直接复制公斤数 |

当次热身校准到的新重量可以成为下一课重复验证的基线；这不等于下一课再额外进阶一次。既有连续两次规则与晨练/停止规则以生效偏好为准，复盘不能静默修改。

### 6.4 输出、档案与确认

每次复盘交付简表：**动作／原处方 → 实际完成及可比历史 → 维持或调整及理由 → 下一次首组/后续重量、组次、余力/质量、休息 → 所缺信息/置信度**。维持也是明确决定；恢复待补时注明候选，取得相关反馈后再定完整下一课。至少考虑一次替代解释，例如休息变短、器械变化、睡眠或顺序变化，而非直接把波动当力量改变。

在[力量表现档案](力量表现档案.md)追加真实新条目：场次/动作/组ID、训练日和证据取得日、原始完成值与独立口径、质量/真实RIR或未知、本人反馈日期、恢复是否已补、下一次候选与复评条件。稳定ID去重，原始App读数与本人澄清分列；原数据被用户更正时追加更正来源，不重复累计或自行改完成组。恢复结论未到时保留“暂定”，后续追加反馈，不伪造已发生记录。

新方案继续展示完整版本、相对上次变化、方法/偏好/力量证据版本和理由，用户确认后才通过现有App入口写入。复盘本身不授权改下一课日程、偏好或Notion；“持续调整”是每次收到新实际与反馈后继续这套流程，技能不等于手机后台算法或自动排程。

### 6.5 怎样判断方法有没有帮上忙

之后每次可比训练回收：建议起点是否需要大幅试重、实际次数与努力目标是否达标、后段质量、实际用时、次晨/下一次活动恢复以及本人接受程度。跨几次同口径观察同一主要调整变量，不把单课顺利、吨位增加或更酸当训练收益证明。RIR本身有误差，优先使用范围和多项表现，不据差1次机械调重。

新训练、口径/器械变化、恢复异常、目标变化或期限结束时重评。关键证据未取得时停止推进加量结论，继续可独立完成的复盘；出现停止条件按当前偏好处理。最小真实验证是下一次完成记录与对应恢复反馈，文档/skill验证不能代替。
