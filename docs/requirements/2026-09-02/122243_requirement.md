## 目标

- 修复“当天训练”动作卡片点击展开失效，以及手指从动作卡片起手时页面无法向下滚动的问题。
- 保留动作排序能力，但把整卡长按拖动改为独立、可见的排序把手，避免与点击和滚动竞争手势。
- 保留底部保存/开始按钮，但不得覆盖或截获动作列表的点击和滑动。
- 移除进行中动作卡片右上角“实际 X/Y 组”角标，保留页面总进度、每组记录及完成能力。
- 从新建、查看和编辑当天计划的用户界面移除“固定重量 / 金字塔递增 / 金字塔递减 / 混合方式”等训练方式概念；用户直接逐组编辑重量、次数、组数与休息。

## 非目标与边界

- 不删除旧计划、历史记录或既有逐组 `plannedSets`，不重写历史数据。
- 内部旧枚举和原始字段可作为导入、导出和旧数据兼容元数据保留，但新用户流程不得展示这些训练方式文案或控件。
- 不改变页面顶部整体“X/Y 组”训练进度，不删除单组完成按钮或单组记录。
- 用户后续已单独授权真机覆盖安装、启动和安装前后数据完整性回读；仍不执行卸载、清容器、真机 XCTest、发布、Git commit、tag 或 push。

## 当前事实

- 当前动作摘要卡整卡挂载长按后拖动手势；模拟器诊断已复现该手势会吞掉从卡片起手的滚动。
- 底部操作栏通过 `safeAreaInset` 固定展示；小屏模拟器已复现其命中区域会截获被覆盖动作卡片的点击，并错误触发“开始训练”。
- 当前计划摘要、当天方式卡、动作编辑器和动作菜单仍展示或操作训练方式；进行中动作卡右上角仍展示“实际 X/Y 组”。
- 当前服务和模型按逐组 `plannedSets` 保存计划，同时保留训练方式原始字段，因此可在不迁移历史的前提下隐藏新流程入口。
