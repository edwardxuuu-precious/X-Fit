- 测试原则：先备份；覆盖安装，不删除旧 App；实际训练记录以历史页为准

## 1. 历史数据准备

可直接把训练截图、备忘录、Excel 或其他 App 导出发给开发者整理。若自行整理 CSV，请复制《X-Fit 历史训练导入模板》并替换示例行。

必需字段：

`session_id, date, workout, exercise, set, weight_kg, reps`

可选字段：

`duration_minutes, workout_notes, muscle_group, equipment, rir, exercise_notes`

填写规则：

- 同一场训练的所有组使用同一个稳定 `session_id`，例如 `20260728-push-a`。
- `date` 支持 `2026-07-28 19:30`、`2026-07-28` 或 ISO 8601。
- 重量统一使用 kg；自重动作可填 `0`。
- 每个完成组单独占一行；`set` 从 1 开始。
- `exercise_notes` 填该动作当次的状态、疼痛、技术提醒或器械差异。
- 相同 `session_id` 再次导入会跳过，避免重复训练。

## 3. 单场手动补录测试

1. 打开 `我的 → 训练历史 → 补录`。
2. 选择过去日期，填写训练名称、时长和训练备注。
3. 选择至少两个动作，为每组填写重量、次数、RIR。
4. 为其中一个动作填写当次注意事项。
5. 保存并回到历史详情核对。

通过标准：

- 保存后直接成为“已完成”历史，不创建等待开始的日程。
- 动作与逐组记录完整；动作注意事项能在详情和下次推荐中回显。
- 再编辑当前训练模板或动作库，不会改写这次历史快照。

## 4. 肌群建议测试

1. 打开底部 `训练 → 今日编排`。
2. 分别选择近期练过的肌群和较久未练的肌群。
3. 阅读每个肌群的恢复状态和建议原因。
4. 检查最近 7 天完成组较多或刚训练过的肌群。

通过标准：

- 建议使用真实完成历史计算，而不是只看计划。
- 状态至少区分：可以训练、适量训练、优先恢复、暂无历史。
- 刚练过或 7 天训练量较高时不会无条件建议高强度重复训练。
- 无历史时明确说明需要先建立基线，不伪造上次表现。

## 5. 动作轮换与菜单编排测试

1. 选择一个有历史的肌群。
2. 记录推荐列表及“上次菜单”标记。
3. 点“换一组推荐”，比较动作排序。
4. 从推荐中选择 3–5 个动作。
5. 调整顺序、组数、次数范围、建议重量和休息时间。
6. 先点“只保存菜单，稍后训练”，重新进入确认菜单仍在。
7. 再选择“保存并开始训练”进入训练进行中。

通过标准：

- 最近同肌群菜单中的动作会被降权，但仍可手动选择。
- 近期较少使用或未出现的动作优先，避免完全复制上一份菜单。
- 点击轮换后有可见变化，且不会自动删除已经手动选择的动作。
- 保存后首页优先显示当天自选菜单；固定周计划仍保留。
- 同一天已有固定计划时，可选择由自选菜单替代；旧计划标记跳过，不被删除。

## 6. 历史详情与训练中调整测试

1. 打开 `我的 → 训练历史`，确认导入名称不再显示 `(Notes)`。
2. 打开任意一天，核对训练日期、时长、容量、动作和逐组重量/次数。
3. 点右上角编辑，修改训练名称/时间/时长、整场训练备注和一个动作备注。
4. 修改一组重量/次数/RIR，增减一组，并补充或删除一个动作后保存。
5. 返回详情，确认容量、逐组数据、训练备注和动作备注均已更新。
6. 返回历史列表，确认页面正常显示，没有黄色警告或空白页。
7. 回到首页，确认“今日训练”右侧没有“查看全部”，再从今天的菜单开始训练。
8. 找到“按今天状态调整训练量”，点“临时加动作”，再为某动作增加一组。
9. 减少最后一个尚未完成的组；尝试移除未开始动作。
10. 点动作卡片右上角“调整训练量”，确认增组、减组和移除未开始动作均在此菜单内。
11. 点表头的 RIR 问号，核对中文说明；关闭后为一组选择“RIR 2 · 还能做 2 次”。
12. 完成一组，确认休息卡显示该动作“计划默认休息 X 秒”和实时倒计时。
13. 分别点击“−30 秒 / +30 秒”，确认倒计时立即变化；完成一组后，确认该动作不能被误删。

通过标准：

- 导入来源不会混入训练名称；用户自己录入的名称不被系统误改。
- 历史详情逐组数据与列表汇总一致；编辑保存后重新计算容量，重复进入和返回均稳定。
- 整场训练备注与动作备注可分别编辑，并在下一次建议中回显。
- 训练中调整即时保存，不会新建第二个进行中会话。
- 已完成组不能被“减组”删除，已经开始的动作不能被整项移除。
- RIR 可理解为保持动作标准还能完成的次数；不确定时允许不记录。
- 每个动作始终显示计划默认组间休息，计时中增减 30 秒不会改写计划本身。

## 7. 上次强度与注意事项测试

1. 在训练页确认当前策略为“减脂容量”，再从推荐列表选择一个过去练过的动作。
2. 核对“上次表现”的日期、训练名称、组数、工作均重、最佳组、平均 RIR 和容量。
3. 核对推荐组数、次数、重量、目标容量和建议理由。
4. 开始当天训练，在动作卡片中检查注意事项。
5. 填写新的动作状态/疼痛/技术提醒，完成训练。
6. 下一次再选择同一动作。

通过标准：

- 上次表现来自该动作最近一次完成记录，不来自未完成训练。
- 缺少 RIR 时不自动加重；保留上次组数并使用工作均重，不直接拿最重一组作为全部工作组重量。
- 容量保持、RIR 完整且每组至少 3 RIR 时才允许可选微加重，并且不减少组数。
- 次数、RIR 或容量未达标时优先减重保组数，而不是用更重重量牺牲训练容量。
- 注意事项优先合并动作库说明、上次动作备注和上次训练备注。
- 新填写的动作备注在历史详情可见，并在下一次推荐时回显。

## 9. 周/月进度可视化测试

1. 打开首页，确认默认显示“本周进度”和周一至周日 7 个刻度。
2. 核对完成训练、工作组、训练容量、分钟和计划数量。
3. 点右上角“月”，确认标题变为“本月进度”，横轴按自然周起始日期显示。
4. 找一个有训练记录的周期，核对柱高与历史容量；再查看一个没有记录的周期状态。
5. 核对“较上周同期 / 较上月同期”只比较相同已过时间，而不是完整上一周期。

通过标准：

- 计划完成率只使用未跳过的周期计划作为分母；没有计划时显示暂无计划。
- 训练次数、工作组、容量和时长只统计已完成训练，热身组不计入工作组容量。
- 周视图 7 个日期、月视图 4–6 个自然周刻度无重叠；零数据不显示虚假柱高。
- 周/月切换后数据与标题同时更新，返回首页不会丢失训练历史。
